# W2: For long papers, keep BM25 passage search or test hybrid retrieval plus reranking?

Research window (UTC): 2026-10-26T20:33:27Z to 2026-10-26T20:35:29Z. The common start is the pilot start; all five questions were in scope throughout.

Recommendation: Keep BM25 as the shipping baseline and run an offline hybrid BM25+dense candidate test; add reranking only as a separately measured ablation, because domain mismatch can hurt.

## Source-linked claims

- QASPER pairs full research papers with human-selected supporting evidence, allowing evidence retrieval to be evaluated separately from answer generation. [Abstract, lines 16-18](https://arxiv.org/abs/2105.03011)
- SciRet found hybrid retrieval more robust than sparse or dense alone in its scientific corpus, but its pseudo-relevance labels were derived from the hybrid system. [Abstract, lines 16-18](https://arxiv.org/abs/2608.03860)
- SciRet reported that an MS MARCO-trained cross-encoder reduced precision on its scientific corpus. [Abstract, line 17](https://arxiv.org/abs/2608.03860)
- A QASPER study examined a retriever-ranker-reader pipeline and reported that stage choices affected answer quality. [Abstract, lines 57-60](https://aclanthology.org/2022.wiesp-1.8/)

Baseline: Existing BM25 passage ranking, fixed passage segmentation and top-k/token budget.

Cheapest matched test: Use the same frozen papers/questions and human evidence sets. Compare BM25, BM25+dense fusion, and fusion+reranker at identical top-k and downstream context token budget; record full-evidence-set recall, answer support, per-query retrieval latency, index size, and memory.

Decision rule: Pilot only if hybrid improves complete human-evidence-set hit by at least 3 questions on 20 answerable cases, with no decrease in human-reviewed supported answers and retrieval p95 latency no more than 25% above BM25. Admit reranking only if it adds at least 2 further complete evidence hits without losing supported answers. Thresholds are local pilot choices.

Uncertainty: The available studies use different corpora and models; SciRet labels risk favoring the hybrid system. Local evidence-hit and latency baselines are unset, so no production switch is justified yet.
