    Method

    How it works

    Search → read → extract → answer with evidence.

    Evaluation sequence

    1. 01
      Freeze questions and source text

      Record question IDs, paper exclusions, corpus revision, and source hashes before running the candidate models.

    2. 02
      Run the same bounded investigation

      Each model writes Python against the same search, read, passage, and extraction tools. Actions and observations are recorded.

    3. 03
      Produce a provisional comparison

      Use deterministic checks for execution and exact spans. A model grader can assess answers against existing QASPER references, but its verdicts are not independent human judgments.

    4. 04
      Inspect failures; optionally validate with people

      Show paired answers and trajectories. If a human-reviewed result is needed, validate source references first, then judge anonymous answers before revealing model identities.
