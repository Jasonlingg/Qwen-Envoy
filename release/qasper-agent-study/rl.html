What would establish an improvement?

The unfinished Prime RL pilot would need a frozen final checkpoint, both V5 and RL answers on the same 12 locked papers, reviewed source support for each material claim, and the predeclared execution, latency, and token gates. A new paid run also needs an always-on controller and a sleep-independent resource deadline. The September confirmation already showed why a development reward gain is insufficient.
