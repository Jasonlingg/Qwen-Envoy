## What an MCP user can do

Search papers, follow citations, open a versioned paper, search its exact
passages, and inspect bounded excerpts without a model. Explicitly configure a
Docker-backed reader to investigate up to five papers in parallel, and optionally
synthesize from its verified packet. Failures retain other verified evidence.
The host must judge whether each quote supports the claim. The default reader
is off even when a provider key exists; normal paid reader use is not dollar
capped. [Setup and limits](../ARXIV_RESEARCH_MCP.md).
