# Nebius x NVIDIA hackathon rules audit

Checked September 26–27, 2026 against the [official rules](https://nebiusglobalaihackathon.devpost.com/rules) and [event resources](https://nebiusglobalaihackathon.devpost.com/resources). This is a project-readiness audit, not a determination by the organizers.

**Finding:** Envoy's proposed Personal AI architecture does not inherently conflict with the rules. The current local prototype is **not yet a qualifying finished submission**. A working app must make a runtime Nebius Token Factory inference call or run on Nebius AI Cloud **and** use an NVIDIA open source model. Qwen alone does not satisfy the NVIDIA-model requirement. A September 27 application-level test made live planning and answering calls to `nvidia/Nemotron-3_5-Lightning` through Token Factory on a synthetic vault. The one-command browser demo still runs offline, and the live path has not been published as a judge-accessible build.

Fine-tuning Nemotron is **not** required. An NVIDIA open source model must have a real application role. Standard Token Factory credits are advertised on the event's own resources page. The rules also contain a broad restriction on projects developed with separate financial or preferential support from the sponsor; if the entrant has special support beyond the published event credits, ask the organizers how that clause applies.

The rules allow technical assistance, subject to entrant ownership and original-work requirements. They do not state that AI-assisted coding is prohibited. The submission should distinguish the recorded live synthetic test from the offline one-command demo and avoid claiming that three valid source references establish semantic correctness.
